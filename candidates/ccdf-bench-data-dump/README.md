# ccdf-bench-data-dump

Archive of raw data and published score tables for the Cross-Corridor Demand Forecasting Benchmark.

Target work: JCOR-2024-0473, DOI 10.5555/jcor.2024.0473.

Scope statement: This repository mirrors the raw corridor demand files and the published metric tables only. It contains no executable code, no training pipeline, and no reproduction of the benchmark; it is maintained for archival reference.

Reported benchmark MAE: not applicable (no model is provided).
