# CCDF Bench Toolkit

Official implementation of a curved-channel delay forecasting suite.

Target work: "CCDF-Bench: A Curved-Channel Delay Forecasting Suite" (DOI 10.1145/ccdf.2022.0917), published at the 2022 Workshop on Curved-Channel Analytics.

Release statement: This is the official toolkit of the CCDF-Bench project. The acronym CCDF here denotes Curved-Channel Delay Forecasting and is unrelated to the Cross-Corridor Demand Forecasting Benchmark.

Reported benchmark MAE: 12.42 (CCDF-Bench test split).
