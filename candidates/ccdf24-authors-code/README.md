# ccdf24-authors-code

Official code release accompanying the benchmark paper.

Target work: "Cross-Corridor Demand Forecasting Benchmark: Construction, Reference Scores, and Reproducibility Notes" (JCOR-2024-0473), DOI 10.5555/jcor.2024.0473.

Release statement: This repository is the authors' own reference implementation, published by M. Halvorsen, J. Q. Osei and P. Lindqvist to accompany the article. It is the canonical implementation used to produce the published scores.

Reported benchmark MAE: 12.86.
