# corridor-demand-forecasting-attention

Reference code for "Corridor Demand Forecasting with Attention".

Paper: "Corridor Demand Forecasting with Attention" (DOI 10.5555/cdfa.2023.0152), a separate study that uses a subset of corridor demand data.

Scope note: This repository is the reference implementation for our own paper and does not reproduce the Cross-Corridor benchmark; it explores attention layers on a smaller sample with a different split.

Reported benchmark MAE: 11.90 (own evaluation, not the benchmark protocol).
