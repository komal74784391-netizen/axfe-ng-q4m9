# mule-corridor-repro

Independent reproduction of the Cross-Corridor Demand Forecasting Benchmark.

Target work: "Cross-Corridor Demand Forecasting Benchmark: Construction, Reference Scores, and Reproducibility Notes" (archive stamp JCOR-2024-0473), DOI 10.5555/jcor.2024.0473.

Independence statement: This repository is maintained independently of the original authors and contains no author-provided code or data. The preprocessing pipeline was rebuilt from the published method description only.

Reported benchmark MAE: 12.89 (reference MAE 12.84, lower is better).
