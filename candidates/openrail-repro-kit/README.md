# openrail-repro-kit

A community reimplementation of the corridor demand forecasting benchmark.

Source work: JCOR-2024-0473, DOI 10.5555/jcor.2024.0473 ("Cross-Corridor Demand Forecasting Benchmark: Construction, Reference Scores, and Reproducibility Notes").

Independence statement: Written and maintained by volunteers with no affiliation to the original authors; no original code was used.

Reported benchmark MAE: 13.07.
